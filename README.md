# spiruxbench results 🎯

Public performance reports for the **AD-100 Benchmark Harness**.

## Overview
The AD-100 harness evaluates LLM coding agents on Python and C++ tasks across:
- **Algorithmic (ALG)**: Data structures and classic algorithms.
- **Debugging (DBG)**: Diagnosing and fixing bugs.
- **Optimization (OPT)**: Improving performance and resource usage.
- **Projects (PRJ)**: Building multi-component tools.

## Data Format
To prevent benchmark contamination (preventing LLMs from being trained on the test data), we publish high-level performance metrics instead of the raw execution traces and logs.

## Available Analytics
Browse the [interactive reports](./index.html) to view:
- **Pass@1 scores** and overall performance.
- **Category breakdowns** (ALG, DBG, OPT, PRJ).
- **Individual challenge results**.
